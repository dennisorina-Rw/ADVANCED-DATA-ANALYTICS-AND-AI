1.3 Pearson Correlation

Hypotheses for Correlation Test:
H₀: There is no significant correlation between weight and miles per gallon (r = 0).
H₁: There is a significant correlation between weight and miles per gallon (r ≠ 0).

Decision Rule: If the p-value is less than the significance level (commonly set at 0.05), we reject the null hypothesis. Otherwise, we fail to reject the null hypothesis. 
# Pearson Correlation (equivalent to cor(mtcars$wt, mtcars$mpg, method="pearson"))
r_pearson, p_pearson = stats.pearsonr(mtcars['wt'], mtcars['mpg'])
print(f"Pearson r: {r_pearson:.5f}")
print(f"p-value:   {p_pearson:.2e}")

# cor.test equivalent
print("\n--- Pearson Correlation Test ---")
print(f"  t-statistic: {r_pearson * np.sqrt((len(mtcars)-2)/(1-r_pearson**2)):.4f}")
print(f"  df: {len(mtcars) - 2}")
print(f"  p-value: {p_pearson:.2e}")
print(f"  alternative hypothesis: true correlation is not equal to 0")

1.4 Spearman Correlation (Non-parametric)

# Spearman Correlation (equivalent to cor(mtcars$wt, mtcars$mpg, method="spearman"))
# R output: -0.886422, p-value = 1.488e-11

print(f"\n--- Spearman's Rank Correlation ---")

SECTION 2: Simple Linear Regression (SLR) – mtcars

Hypotheses for Overall Model Significance (F-test):
H₀: The overall regression model is not statistically significant (the model does not explain a significant portion of the variance in miles per gallon).
H₁: The overall regression model is statistically significant (the model explains a significant portion of the variance in miles per gallon). 
# =============================================================================
# SECTION 2: SIMPLE LINEAR REGRESSION (SLR) - mpg ~ wt
# =============================================================================

# Fit SLR model (equivalent to lm(mpg ~ wt, data = mtcars))
model_slr = smf.ols('mpg ~ wt', data=mtcars).fit()

# summary(model_slr) equivalent
print("\n--- SLR Model Summary (mpg ~ wt) ---")
print(model_slr.summary())

# 95% Confidence Intervals for Coefficients
print("\n--- 95% Confidence Intervals ---")
print(model_slr.conf_int(alpha=0.05))

# Prediction for a new car with wt = 3.5
# (equivalent to predict(model_slr, newdata=data.frame(wt=3.5), interval="confidence"))
new_car = pd.DataFrame({'wt': [3.5]})
pred_slr = model_slr.get_prediction(new_car).summary_frame(alpha=0.05)
print("\n--- Prediction for wt = 3.5 ---")
print(pred_slr[['mean', 'mean_ci_lower', 'mean_ci_upper', 'obs_ci_lower', 'obs_ci_upper']])
📝 Note: In R, predict(..., interval="confidence") gives the confidence interval for the mean response, while interval="prediction" gives the prediction interval for a new observation. In Python, get_prediction().summary_frame() returns both: mean_ci_* = confidence interval, obs_ci_* = prediction interval.

SECTION 5: Regression Diagnostics – Normality

Null and Alternative Hypotheses for Normality:
H₀: The residuals of the model are normally distributed.
H₁: The residuals of the model are not normally distributed. 
# =============================================================================
# SECTION 5: NORMALITY TESTS
# =============================================================================

residuals_mlr = model_mlr.resid

# Shapiro-Wilk Test (equivalent to shapiro.test(residuals(model_mlr)))
# R output: W = 0.92792, p-value = 0.03427
stat_sw, p_sw = stats.shapiro(residuals_mlr)
print(f"\n--- Shapiro-Wilk Normality Test ---")
print(f"  W = {stat_sw:.5f}")
print(f"  p-value = {p_sw:.5f}")

# Anderson-Darling Test (equivalent to ad.test(residuals(model_mlr)) from nortest package)
# R output: A = 0.66581, p-value = 0.07456
ad_result = stats.anderson(residuals_mlr, dist='norm')
print(f"\n--- Anderson-Darling Normality Test ---")
print(f"  A = {ad_result.statistic:.5f}")
# Note: scipy's anderson() gives critical values at different significance levels
# For p-value approximation, we use the 5% critical value comparison
print(f"  Critical values: {ad_result.critical_values}")
print(f"  Significance levels: {ad_result.significance_level}")
if ad_result.statistic > ad_result.critical_values[2]:  # 5% level
    print("  Decision: Reject H0 at 5% significance (not normal)")
else:
    print("  Decision: Fail to reject H0 at 5% significance (normal)")

5.1 Q-Q Plot

# Q-Q Plot (equivalent to ggplot + geom_qq() + geom_qq_line())
fig = sm.qqplot(residuals_mlr, line='s', fit=True)
plt.title("Q-Q Plot of Residuals")
plt.xlabel("Theoretical Quantiles")
plt.ylabel("Sample Quantiles")
plt.tight_layout()
plt.show()

5.2 Histogram of Residuals

# Histogram (equivalent to ggplot + geom_histogram(binwidth=0.5, fill="steelblue"))
plt.figure(figsize=(9, 5))
sns.histplot(residuals_mlr, bins=12, kde=True,
             color='steelblue', edgecolor='black')
plt.title("Histogram of Residuals")
plt.xlabel("Residuals")
plt.ylabel("Frequency")
plt.tight_layout()
plt.show()

SECTION 6: Regression Diagnostics – Homoscedasticity

Hypotheses for Homoscedasticity:
H₀: The residuals of the model have constant variance (homoscedasticity).
H₁: The residuals of the model do not have constant variance (heteroscedasticity). 
# =============================================================================
# SECTION 6: HOMOSCEDASTICITY TEST (Breusch-Pagan)
# =============================================================================

# Breusch-Pagan Test (equivalent to bptest(model_mlr) from lmtest package)
# R output for mtcars MLR: BP = 0.88072, df = 2, p-value = 0.6438
bp_stat, bp_pval, bp_fval, bp_fpval = het_breuschpagan(residuals_mlr, model_mlr.model.exog)
print(f"\n--- Breusch-Pagan Test (mtcars MLR) ---")
print(f"  BP statistic: {bp_stat:.5f}")
print(f"  p-value: {bp_pval:.4f}")
print(f"  df: {model_mlr.model.exog.shape[1] - 1}")

if bp_pval < 0.05:
    print("  Decision: Reject H0 → Heteroscedasticity detected")
else:
    print("  Decision: Fail to reject H0 → Homoscedasticity assumed")

SECTION 11: Durbin-Watson Test (Independence of Residuals)

Hypotheses for Independence:
Null: Residuals have no autocorrelation (are independent).
Alternative: The residuals exhibit autocorrelation (are not independent).

Note: Durbin-Watson statistic ranges from 0 to 4. A value near 2 indicates no autocorrelation. Values near 0 indicate positive autocorrelation; values near 4 indicate negative autocorrelation.

⚠️ Important Notes:
  • This script is linear — no functions are defined. Every step executes sequentially.
  • Custom CSV files (htn_dat.csv, training model.csv, demand_data.csv) must be in the same working directory as the script.
  • The mtcars and economics datasets are loaded from the Rdatasets GitHub repository and require internet connectivity.
  • R's log() is natural log. Python's equivalent is np.log(). Inside statsmodels formulas, use np.log() directly.

  • Anderson-Darling in R (nortest::ad.test) gives a p-value directly. Python's scipy.stats.anderson gives critical values at fixed significance levels instead.
